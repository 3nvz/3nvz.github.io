Copernicus Security Research API Validator

Private, single-user security research integration

The API Validator is used to test authorization boundaries with accounts, businesses, ad accounts, and assets owned and controlled by the researcher. It is not a consumer service and does not provide public sign-up.

Purpose

The integration makes narrowly scoped, reversible API requests to validate suspected authorization issues and support responsible vulnerability disclosure. It does not intentionally access third-party data, run ad campaigns, or process Pins or Boards.

Data handling

OAuth credentials and controlled test identifiers remain on the research workstation. Request evidence is minimized and secrets are excluded from logs and reports. See the privacy policy for details.
